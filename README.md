# Mr. Liquete's Exam Prep

Password-protected practice exams for nursing students, with rationales, test-taking strategies, NGN case studies, and a results page that shows what to study next.

**Open the app:** https://patliq.github.io/exam-prep/

The exam content is encrypted. Students need the class password from Mr. Liquete to open it.

Independent practice material. Not affiliated with or endorsed by Elsevier or HESI. For study only, not for patient care.
